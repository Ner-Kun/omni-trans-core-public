# Настройки

Рабочие настройки лежат в `settings/` и в git не попадают: там API-ключи и прокси.

- `settings/global/app_settings.yaml` — общие настройки: провайдеры, ключи, тема, язык интерфейса.
- `settings/global/connections/*.yaml` — подключения к провайдерам.
- `settings/global/prompts/*.md` — профили промптов.
- `settings/lgt_app/app_settings.yaml` — настройки переводчика: языки, недавние файлы.

Этот каталог — только памятка. Реальные файлы создаются приложением при первом запуске.
